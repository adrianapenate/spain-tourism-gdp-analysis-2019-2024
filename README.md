# Tourism in Spain: Analysis and Contribution to GDP (2019–2024)

Data analysis project focused on the evolution of tourism in Spain between 2019 and 2024 and its contribution to the country's GDP.

## 📊 Project Overview

The project analyzes tourism activity across Spanish Autonomous Communities, focusing on:

- Number of tourists
- Overnight stays
- Average trip duration
- Tourism expenditure
- Tourism contribution to GDP
- Tourism trends and seasonality

The analysis also studies the impact of the COVID-19 pandemic and the subsequent recovery of the tourism sector.

## 🗂️ Data

The project uses three main datasets:

- `TurismoEspaña.xlsx` — Monthly tourism data by Autonomous Community (2019–2024).
- `GastosTurismo.xlsx` — Quarterly tourism expenditure data (2018–2024).
- `PIBTurismo.xlsx` — Tourism-related GDP indicators (2015–2023).

Main data sources include the **Spanish National Statistics Institute (INE)**, **Turespaña**, **Exceltur**, and the **Bank of Spain**.
